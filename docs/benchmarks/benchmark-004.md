# Benchmark 004 — 语义评估与字面覆盖的边界

历史观察：2026-05-08。仓库摘要保留评估机制分析；个人简历、原始样本评分和运行产物不属于应用发布资产。

## 原问题

按正文关键词出现次数计算覆盖，无法处理同义表达、技术词只出现在上下文或正文没有实际呈现证据等情况。规则覆盖与语义覆盖应分别表达依据，不用加权后的单一分数掩盖事实缺口。

## 模型评估的约束

- 语义结论必须指向本次完整 JD、实际正文位置和可回读证据。
- 模型认为“更自然”“更可信”不等于原文成立；捏造风险分不能自证事实保真。
- 未评项、无效引用、未知环境和缺失测量条件应保持明确状态，不补零或伪造通过。
- 同版本输入可复用已验证的缓存；来源或正文变化后，旧结论不能继续取得权威。

## 验证方法

使用明确合成材料测试相同关键词但不同职责、语义相关却无字面重合、证据池有事实但正文未呈现，以及来源/正文修订变化。每个预期独立于被测模型或评分实现定义。应用端到端效果仍须通过完整 pipeline 和相应真实 App 验收确认。

当前合成入口见 [Benchmark 001](benchmark-001.md)，分层判据见 [简历质量规范](../../openspec/changes/resume-quality-standard-and-evidence-inference/specs/resume-quality/spec.md)。
