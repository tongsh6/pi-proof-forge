# Benchmark 002 — Stack Field Consumption

历史观察：2026-05-08。本文记录应用实现的前后差异；个人样本、卡 ID 和运行评分不随应用资产发布。

## 变更与根因

匹配引擎原先未消费 EvidenceCard.stack；补入该字段后，具有不同技术栈证据的卡不再因读取遗漏而全部等分。领域模型与存储加载器必须共同传递字段，单改评分函数不能保证入口真的有数据。

## 不能从该修复推出的结论

字段已读入不等于岗位语义匹配成立。相同技术词不能证明相同职责、环境或成果；没有字面重合也不能直接否定可迁移经验。生成未呈现的事实不能因为证据池中存在就取得正文覆盖分。

## 可重复的工程验证

使用合成证据卡，通过应用真实加载路径比较“stack 中有事实 / 无对应事实 / 仅名称相同但职责不同”的独立预期。输入、引用、报告与实际正文共同核对；不以被测实现的分数反推期望值。
